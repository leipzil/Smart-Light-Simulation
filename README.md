This smart light program simulates many of the real functions of a smart light controller app. It lets a user manage the lights in different rooms of a house, with a login system to keep the settings private. The program is built with while loops, functions, a class, if-else logic, and Python’s pickle module for saving data. It can do the following:
1. Create an account and log in with a password
2. View, add, and remove rooms
3. Control each room’s light, including its status (on/off), mode (cool/warm), and brightness
4. Save all data automatically so it’s still there the next time the program runs
